# Интерфейсы человек–ЭВМ: ЛР1 и ЛР2

Приложение с графическим интерфейсом (Python + PySide6 + matplotlib) для двух лабораторных работ:

- **ЛР1. Оценка временных характеристик диалога.** Имитационная модель времени решения задачи в
  диалоговой системе с двумя подтемами: вероятности маршрутов и подтем, разные законы распределения
  времени шага, три процедуры обработки ошибок, гистограммы для нескольких значений P,
  K = int(1 + 3.22·lg N), сравнение с аналитическим матожиданием.
- **ЛР2. Оценка эффективности человеко-машинной системы.** Диспетчер РЭС обслуживает поток заявок
  (подтема 1); система отказывает, диспетчер её восстанавливает (подтема 2). Показатель —
  средние удельные потери Q = (R1·Στ + R2·Σθ)/T с доверительным интервалом. Есть исследование
  влияния параметров диспетчера (P ошибки, темп работы) и системы (λ, наработка на отказ).

## Запуск (macOS)

Нужен Python 3.10+ (`python3 --version`).

```bash
./run.sh
```

При первом запуске скрипт создаёт виртуальное окружение `.venv` и ставит зависимости из
`requirements.txt`. Это занимает 1–2 минуты. Вручную то же самое:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

## Вкладки

| Вкладка | Что делает |
|---|---|
| **Граф диалога** | Шаги (закон распределения и параметры), маршруты (вероятность, последовательность), вероятность выбора подтемы и ошибки. Справа схема графа, внизу проверка данных. Файл → Открыть/Сохранить (JSON). |
| **ЛР1: время диалога** | N, список P (по умолчанию `0; 0.3; 0.6; 0.9`), процедура обработки ошибок, «Моделировать». Гистограммы для темы или отдельной подтемы, K задаётся формулой или вручную без повторного моделирования, таблица частот и сводная таблица средних. |
| **ЛР2: эффективность** | Параметры потока заявок, отказов, потерь и диспетчера. Результат: Q и его составляющие, Kг, задержки, загрузка, график очереди. |
| **ЛР2: исследование** | Перебор одного параметра в диапазоне и графики Q(параметр) с доверительной полосой. |

Графики можно масштабировать и сохранять в PNG кнопками панели над ними.

## Отчёты

```bash
.venv/bin/python report/make_report.py
```

Скрипт проводит все эксперименты с фиксированным зерном и собирает `report/Отчёт_ЛР1.docx` и
`report/Отчёт_ЛР2.docx` (около 40 секунд). На титульных листах нужно вписать кафедру, группу и ФИО.

## Структура

```text
main.py                  точка входа GUI
run.sh                   запуск с автоматической установкой зависимостей
data/energy_dispatch.json   вариант: граф диалога АРМ диспетчера РЭС
hmi_lab/
  model.py               шаги, маршруты, подтемы, тема; чтение/запись JSON; проверка
  dialog_sim.py          ЛР1: моделирование диалога, аналитические оценки, гистограмма
  efficiency_sim.py      ЛР2: событийная модель «заявки — отказы — восстановление»
  gui/                   окно и вкладки
report/make_report.py    генерация отчётов .docx
task/                    методические материалы
```
