# Интерфейсы человек–ЭВМ: ЛР1 и ЛР2

Приложение с графическим интерфейсом (Python + PySide6 + matplotlib) для двух лабораторных работ:

- **ЛР1. Оценка временных характеристик диалога.** Имитационная модель времени решения задачи в
  диалоговой системе с двумя подтемами: вероятности маршрутов и подтем, разные законы распределения
  времени шага, три процедуры обработки ошибок, гистограммы для нескольких значений P,
  K = int(1 + 3.22·lg N), сравнение с аналитическим матожиданием.
- **ЛР2. Оценка эффективности человеко-машинной системы.** Диспетчер распределительной электросети обслуживает поток заявок
  (подтема 1); система отказывает, диспетчер её восстанавливает (подтема 2). Показатель —
  средние удельные потери Q = (R1·Στ + R2·Σθ)/T с доверительным интервалом. Есть исследование
  влияния параметров диспетчера (P ошибки, темп работы) и системы (λ, наработка на отказ).

## Запуск (macOS)

Нужен Python 3.10+ (`python3 --version`).

```bash
./run.sh
```

При первом запуске скрипт создаёт виртуальное окружение `.venv` и ставит зависимости из
`requirements.txt`. Это занимает 1–2 минуты. Вручную то же самое:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

## Разделы программы (боковое меню слева)

1. **Исходные данные.** Шаги и маршруты двух подтем, вероятности. Уже заполнено, можно не трогать.
   Кнопки «Открыть файл» / «Сохранить в файл».
2. **ЛР1 — время диалога.** Ввести N и значения P → «Моделировать». Гистограммы для каждого P и
   таблица средних. Число интервалов K можно поменять после расчёта.
3. **ЛР2 — эффективность.** Параметры системы → «Рассчитать»: показатель Q, его составляющие и
   график очереди. Ниже — «Построить зависимость»: как Q меняется от P ошибки или темпа диспетчера.

## Отчёты

```bash
.venv/bin/python report/make_report.py
```

Скрипт снимает скриншоты программы, проводит эксперименты (зерно генератора 2026, поэтому числа
воспроизводимы) и собирает `report/Отчёт_ЛР1.docx`/`.pdf` и `report/Отчёт_ЛР2.docx`/`.pdf`.
Оформление: поля 2 см, Times New Roman 14, интервал 1,25, номер страницы внизу, титульный лист по
образцу кафедры АСУ. Номера страниц в содержании настоящие: скрипт переводит документ в PDF через
Microsoft Word, смотрит, где начинается каждый раздел, и собирает документ ещё раз (около 3 минут).
Без Word: `--no-pdf`, тогда номера в содержании пустые.

ФИО, группа и преподаватель задаются в словаре `STUDENT` в начале `report/make_report.py`.
